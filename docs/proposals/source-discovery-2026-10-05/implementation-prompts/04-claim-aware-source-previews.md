## Phase-specific task

Prerequisite: verify Phases 1–3. Improve the information used to decide which acquired sources deserve deep analysis. Current Probe scoring rewards numbers, citations, and conclusion-like text; saved ALPR previews included unrelated bibliography entries. Replace that weakness without weakening quotation or source rules.

## 1. Build useful windows from authoritative snapshots

Use the frozen exact claim, asserted components, current target gaps, immutable snapshot ID/hash, and normalized snapshot text to create deterministic preview candidates. Support multilingual/Unicode text conservatively. Identify likely title/abstract/methods/results/discussion/conclusion sections when observable, with explicit unknown section status when not. Recognize numbered headings, flattened HTML, and PDF page markers. Avoid bibliography, citation-only fragments, DOI fragments, recommended articles, menus, cookie controls, and page-error text dominating selection.

Score contextual windows for claim-component relevance and substantive method/result content. Combine term/phrase aliases with structural and statistical signals; do not rank by digits alone. Preserve negative/null findings and qualifying language. Select a bounded, non-overlapping, useful set of contiguous windows instead of isolated sentence fragments such as “DOI 10.” Merge only adjacent spans when exact source continuity can be preserved; never stitch noncontiguous text and present it as a single quote.

All preview text must equal the exact substring at its recorded offsets in the existing immutable normalized snapshot. Validate ID/hash/run ownership, offsets, text, order, overlap, and truncation/context markers. Retain context sufficient to distinguish findings from references and author claims from quoted commentary. Do not fabricate omitted sections, regenerate text, paraphrase a preview, expand the snapshot cap, or splice content from another document/version. Missing methods/results after truncation must be reported as missing/unknown. Search abstracts/snippets can help metadata ranking but cannot supply snapshot preview passages or admitted evidence.

## 2. Preserve usability and introduce conservative completeness

Version the preview/Probe policy and current/historical dispatch. Current shell rejection is already implemented and must remain. Distinguish preview relevance from acquisition usability: a low relevance score is not proof the document is useless, and a detailed abstract/landing page is not automatically full text. Add conservative full-text/abstract/landing/error/unknown capture diagnostics only when observable; do not invent a full-document verification based on text length. Keep failed snapshots and reason records inspectable. Handle empty, shell-only, citation-only, and truncated snapshots explicitly.

Use bounded deterministic lexical/structural scoring first; a new embedding service or model call is not required. If a demonstrably necessary model-assisted preview step is added, it must have a complete selectable route, typed output, exact span validation, prompt-injection boundary, frozen identity, token/cost reservation, strict call cap, and fallback. It must never replace the complete authoritative snapshot used by exact extraction or make factual/admission decisions.

## 3. Wire previews into actual selection

Update acquisition/Probe handoffs, final Source Selection input/prompt/schema, source status/rank rationale, inspection/export readers, and trail presentation to use the new typed preview result. Keep metadata ranking from Phase 3 distinct from preview-informed source ranking; retain both decisions so we can explain why an initially promising source was demoted or retained. Allow relevant methods/results to outweigh a weak-looking title, and bibliographic/abstract-only content to lower confidence in a source's usefulness without laundering it into full-text evidence.

Bound passage counts, window lengths, per-source preview characters, and total selection input tokens. Reserve the complete actual rendered model input and output allowance before transport. If the survivor pool cannot fit, use a deterministic audited shortlist or separately bounded batches with explicit omitted-source dispositions; do not truncate an arbitrary JSON string or silently lose sources. Do not promote recommendations into evidence-quality/claim-fit scores or change final release invariants.
